## 📌 Project Description
This is a basic network packet sniffer developed in Python using the Scapy library. This project captures live network traffic and displays critical information like Source IP, Destination IP, and Protocol type.

This project was completed as part of the CodeAlpha Cyber Security Internship Task 1.

## ✨ Features
- Captures live network packets in real-time
- Extracts and displays Source IP & Destination IP
- Identifies the protocol of each packet
- Timestamp for each captured packet
